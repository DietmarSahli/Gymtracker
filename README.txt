GYMTRACKER – erste Version

Dateien:
- index.html: App
- manifest.webmanifest: PWA-Metadaten
- sw.js: Offline-Caching

WICHTIG:
Diese Version speichert Daten lokal im Browser (localStorage). Sie synchronisiert NICHT automatisch zwischen iPhone und PC.
Für die Installation als PWA auf dem iPhone und PC muss sie über eine HTTPS-Webadresse bereitgestellt werden.
Ein kostenloses Hosting (z.B. GitHub Pages) ist möglich, benötigt aber ein Konto und eine einmalige Einrichtung.
Für automatische Synchronisation ist zusätzlich ein Cloud-Datendienst nötig; ein Gratis-Tarif kann Limits oder Änderungen haben.

Empfohlener nächster Schritt:
Gemeinsam kostenloses Hosting und danach eine kostenlose Datenbank/Synchronisation einrichten.
